# BlocksCreate 1

> **ITERATION / HISTORICAL SNAPSHOT**

An early BlocksCreate experiment preserved as part of the project's evolution. This repository currently contains only a small asset/style snapshot rather than the complete modern game.

The active, substantially more developed project is [blockscreate](https://github.com/joaoccaldas/blockscreate).

## Why keep this repository?

It documents an early stage of the idea and helps show how the project evolved. It should not be treated as the canonical implementation or used as the basis for new shared infrastructure.

## Project context

This is a personal, self-directed learning project by João Caldas. AI tools are used extensively during research, design, coding, debugging, testing, asset ideation, and documentation as part of the learning process. AI output is treated as input to review rather than proof of correctness.
